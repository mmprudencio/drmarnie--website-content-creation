# PRD — Dr. Marnie Website & Content Platform

## Problem
Dr. Marnie needs a website she fully owns (not rented) to inform patients, publish daily expert content, promote books/courses, and capture leads — with full control over every word published.

## Target User
Primary owner: Dr. Marnie (content publisher, lead manager).  
Visitors: Parents and patients seeking pediatric/developmental guidance.

## Core Objects
- **Post** — article/educational content piece
- **Service** — appointment info or service offering
- **Product** — book or course listing
- **Lead** — visitor who left contact info
- **Page View** — anonymous visit event per path

## MVP Checklist (v1 must-haves)
- [ ] Public homepage showing published posts, services, products
- [ ] Individual post pages with full content
- [ ] Lead capture form (name, email, phone) on every page
- [ ] Admin panel: create / edit / publish / unpublish posts
- [ ] Admin panel: manage services and products
- [ ] Admin panel: view leads list
- [ ] Page view tracking (path + timestamp, no personal data)
- [ ] Site live on custom domain via Vercel

## Non-Goals (v1)
- User accounts / patient login
- Payment processing or course delivery
- Newsletter automation
- Comments or community features
- Multi-author workflows

## Success Criteria
Dr. Marnie opens the admin panel, writes a post about early speech delay, publishes it, and a visitor on the homepage sees it, fills in the lead form, and that lead appears in the admin leads list — all without touching code.
